# BOVEDA DE VIDEOJUEGOS

## Sobre el proyecto

En esta demo presentamos tres funciones principales de nuestro sistema de videojuegos: buscar juegos y consultar su información, recibir recomendaciones según géneros y ver un Top 10 según el rating. El objetivo es ayudar a los jugadores a encontrar nuevos juegos similares a los que ya disfrutaron.

## Requisitos

- Python 3.13
- Pandas

## Como ejecutar el programa

1. Descargar o clonar el proyecto

2. Abrir la carpeta del proyecto

3. Instalar Pandas:


"pip install pandas"


4. Ejecutar el archivo principal:


"phyton main.py"


## Como utilizar el programa

Al iniciar el programa aparecerá un menú con las siguientes opciones

### 1. Buscar un videojuego
Permite ingresar el título de un videojuego y consultar su información:
- Título
- Fecha de lanzamiento
- Rating
- Géneros

### 2. Recomendar por género
Permite ingresar un género y muestra hasta 5 videojuegos recomendados, ordenados según su rating.

### 3. Ver Top 10
Muestra los 10 videojuegos con mayor rating dentro del dataset.

### 4. Salir
Cierra el programa.


## Dataset

El programa utiliza un archivo CSV con información de videojuegos, incluyendo datos como titulo, fecha de lanzamiento, genero y rating.
