# Bóveda de Videojuegos

'' Sistema de búsqueda y recomendación de videojuegos desarrollado en Python. ''

# Funcionalidades

* Búsqueda de videojuegos por título.

* Consulta de información.

* Recomendaciones por género.

* Top 10 según rating.

* Búsqueda mediante ABB y AVL.

* Recorridos Inorder, Preorder y Postorder.

* Organización de categorías mediante un árbol general.

* Comparación de alturas y tiempos de búsqueda.

* Pruebas de rendimiento con diferentes cantidades de elementos.

# Tecnologías

"Python 3.13"

"Pandas"

# Instalación y ejecución

* Instalar la dependencia:

```bash
pip install pandas
```

* Ejecutar el programa:

```bash
python main.py
```

# *El archivo games.csv debe estar en la ubicación esperada por el programa.*

# Estructuras de datos

* ABB: organiza los videojuegos por título y permite realizar búsquedas y recorridos.

* AVL: mantiene el árbol equilibrado para mejorar el rendimiento de las búsquedas.

* Árbol general: organiza los géneros, las décadas de lanzamiento y los rangos de valoraciones.

# Pruebas de rendimiento

* Se comparan las estructuras utilizando hasta 100, 1.000, 10.000 y 100.000 títulos, según los datos disponibles.

* Se registran los tiempos de construcción y búsqueda, además de las alturas de los árboles.
